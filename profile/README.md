# Parch Linux

Parch Linux is a rolling-release, Arch-based GNU/Linux distribution focused on delivering a clean, modern, and practical Linux experience.

## About

Parch Linux follows Arch Linux principles while improving the out-of-box experience with sensible defaults, lightweight components, and practical tooling.

The project focuses on simplicity, performance, transparency, and staying close to upstream.
